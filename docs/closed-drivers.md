# Redmi Note 13 4G (sapphire): public sources for the closed Xiaomi/Longcheer modules

Date: 2026-11-14. Stock modules come from `/home/angel/sapphire/x/vendor_dlkm/lib/modules` and `/home/angel/sapphire/unpacked/vrd/lib/modules` (5.15.94 GKI).
All candidates were shallow/sparse-cloned into WSL at `/home/angel/sapphire/srcpool/` (705 MB in total). Nothing under `ws/` or `src/` was touched.

## How the scores were measured

Each candidate was checked against the stock `.ko` binary itself. A match on the file name alone did not count.

* **TEXT %** is the share of the stock module's human-readable strings found in the candidate's C string literals: printk formats, sysfs/proc names, DT property names and messages that contain a space or `%`. Before comparing, `\001N` KERN_* prefixes and `pr_fmt` prefixes like `[FTS_TS/E]%s:` or `[USBPD-PM]: %s: ` are stripped. Literal fragments split across adjacent quotes are joined back together.
* **T-syms** is the share of the stock module's global text symbols (`nm` type T, without `__cfi_check`/`__typeid__*` CFI artifacts or init/cleanup) that are defined or referenced as identifiers in the candidate.
* Where they could be checked, the DT `compatible` strings (from `modinfo -F alias`) and `module_param` names were compared too.
* Some misses can be ignored. These include CFI type strings (`'int (void)'`), `description=`/`author=` modinfo strings, random `.rodata` byte runs and debug-only prints.
* Tools (persistent copy): `/home/angel/sapphire/srcpool/_tools/{score.py,scoreall.sh,bestfile.py,sclone.sh}`.
  `python3 -I score.py <stock.ko> <srcdir>...` prints the scores. Set `V=1 N=40` to also list the misses.
* Stock strings, modinfo and T-symbol lists are in `/home/angel/sapphire/srcpool/_stock/`.

## Summary by effort

* **Essentially done** (official or near-exact source, at least 85% of strings and nearly all symbols): stm_nfc_i2c, nxp-nci, the millet family + binder_gki (dijun-v-oss), perf_helper (bixi), mi_memory (sky), mi_wmark (bixi), miev (piano), bootinfo (sky), swinfo (dada-v-oss), binder_prio (ChicKernel), lct_audio_info, lct_tp (spes), sc8541_charger and bq25960_charger (samsung bengal sc8541.c plus a rename).
* **Good base, small additions needed:** focaltech_ts_i2c (spes ft3418_i2c + FT3519T ft5452j bits + FOD/gesture/panel-notifier glue), xiaomi_fp (sm8635 mi_fp / tanzanite + goodix panel notifier), xiaomi_touch_game (FOD press sysfs), ds28e30/slg/stick_verify (library code matches; front-end and GPIO glue need adapting to Qualcomm/khaje).
* **Partial, real porting work needed:** pd_policy_manager (the N7 CP-mode/low_fast/smart-chg layer is not public), cp_qc30 (5.15 IIO + BQ25960/SC8541 notifiers), xm_smart_chg (Qualcomm smb5/IIO/panel glue, about 30%), auth_battery and battery_auth_class (IIO wrapper and onewire merge).

## Notes

* Mayuri-Chan/android_kernel_xiaomi_moon's `battery_secrete/{ds28e30,slg,stick}_verify.c` are 400-byte stub files. The real code is in **picasso09/android_kernel_xiaomi_moon** and **linastorvaldz/kernel_xiaomi_gold**, and the Qualcomm SM4450 version is in **Niyush-04/kernel_xiaomi_sm4450**.
* `xm_smart_chg` has `softdep pre: qpnp-smb5-main`, and focaltech depends on `qpnp-smb5-main`. So the Xiaomi-modified smb5 (`qpnp-smb5-main.ko`) is also part of the closed charger stack. It was not in scope here, but MiCode spes-r-oss `drivers/power/supply/qcom/` (4.19, Longcheer) is the closest public lineage.
* klarnet2009/dada-closed-modules (`srcpool/dada/repo`) is a 2026 reverse-engineering project for the Xiaomi 15 (6.6). Its per-module `STATUS.md` names the official MiCode template branch for each module. That is how the dijun/bixi/piano/dada-v-oss sources were found.
* Other cloned candidates that were scored but lost: `srcpool/charger/{moon,tanzanite,sm8250,topaz,sunstone,spes515,mojito,samsungqti}`, `srcpool/mi/{zeus,sea,warm,light,garnet}`, `srcpool/tp/surya`, `srcpool/fp/{sm7325,adarsh,onyx}`, `srcpool/audio/gale`, `srcpool/modules/sm6375`.
* A community tree `Angelpro09xd/kernel_xiaomi_sapphire` exists (likely yours) and was not evaluated. `crdroidandroid/android_kernel_xiaomi_sapphire` and the `*sapphire-kernel` repos are prebuilt-only.
